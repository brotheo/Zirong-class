A2 · Reading input: cin or getline?

The getline trap

After cin >> age; the Enter key is still waiting in the input. A getline straight after it reads that Enter and gives you an empty string. Throw it away first:

cin >> age;
cin.ignore(1000, '\n');   // throw away the Enter left behind
getline(cin, name);

A3 · Characters and length

Each character has an index, starting at 0, just like an array. A single character uses single quotes and the type char.

string word = "CODE";      //  C  O  D  E
                           //  0  1  2  3
cout << word[0];           // C
cout << word.length();     // 4
cout << word[word.length() - 1];   // E  (the last character)

word[0] = 'M';             // change one character: "MODE"
char first = word[0];      // 'M'

A4 · Looping through a string

This is the same loop you used for arrays. Store the length in an int first.

string word = "CODE";
int n = word.length();
for (int i = 0; i < n; i++) {
    cout << word[i] << "-";    // C-O-D-E-
}

You can also build a new string one character at a time with +=:

string result = "";
result += 'H';
result += 'i';             // result is now "Hi"

Part B: string tools and functions

B1 · Comparing strings

== and != check if two strings are exactly the same. < and > compare in dictionary order, character by character.

string a = "apple", b = "banana";
if (a < b)  cout << "apple comes first";     // true
if ("Zebra" < a) cout << "Surprise!";         // also true: every capital comes before every small letter
if (a == "Apple") cout << "same";             // false: case matters

Not found?

When find cannot find the text it returns the special value string::npos. Always check for it before you use the result:

if (s.find("X") == string::npos) {
    cout << "No X in this word";
}

B4 · Strings and functions

Pass a string as const string& when the function only reads it. This avoids copying the whole string. Functions can return a string too.

string shout(const string& s) {
    string result = "";
    int n = s.length();
    for (int i = 0; i < n; i++) {
        result += char(toupper(s[i]));
    }
    return result + "!";
}
// shout("hi there")  ->  "HI THERE!"

Why char(...)? toupper gives back a number (the character code). char(...) turns it back into a character before adding it to the string.
