Strings in C++ "text"

A 90-minute lesson. Students learn to store, read and process text with std::string, then use it in six timed challenges and a password-checker project. Every solution below was compiled with g++ (no warnings), and every expected output comes from a real run.

Length: 90 minPrior learning: loops, 1D/2D arrays, functions, input validation loopsWork time: 53 of 90 min
Learning objectives
  • Choose between cin >> and getline, and avoid the getline trap
  • Index and loop through a string; build strings with +=
  • Compare strings and use substr, find, insert, erase, replace
  • Classify characters with <cctype>
  • Write functions that take const string& and return string
Success criteria
  • All students: Challenges 1–3 working
  • Most students: Challenge 4, and the project scores Weak / Medium / Strong correctly
  • Some students: Challenge 5 or 6, and the full project with the confirm loop and tips

Discussion

  • Point out that this is exactly how they looped through arrays. A string is a sequence of characters.

Part A: teaching notes

Live demo: the getline trap (3 min)

Type this program and run it without the cin.ignore line first. The name comes out empty. Then add the line and run it again.

#include <iostream>
#include <string>
using namespace std;
int main() {
    int age;
    string name;
    cout << "Age: ";
    cin >> age;
    cin.ignore(1000, '\n');   // throw away the Enter left behind
    cout << "Full name: ";
    getline(cin, name);
    cout << name << " is " << age << endl;
}
Age: 15
Full name: Ada Lovelace
Ada Lovelace is 15

Explain it with the picture of an input "queue": cin >> age takes 15 and leaves the Enter (\n) behind. getline reads up to the first \n it finds, which is that leftover one, so it returns at once.

Misconceptions to watch for

  • 'a' vs "a": single quotes are a char, double quotes are a string. word[0] = "M"; will not compile.
  • Last index: word[word.length()] is one past the end. Like arrays, there is no error message, just wrong results.
  • Spaces count: "Ada Lovelace".length() is 12, not 11.
  • + with two literals: "Hi" + "there" does not compile. At least one side must be a string variable.

Questions to ask

  • "What is "CODE"[2]?" (D)
  • "How would you print a string one character per line?"
  • "If result starts as "", what is it after three += 'x'?" (xxx)

Challenge 2 · Vowel counter

easy7 min · 0:25

Practises: looping through characters, tolower, isalpha, a bool helper function

#include <iostream>
#include <string>
#include <cctype>
using namespace std;

bool isVowel(char ch) {
    ch = tolower(ch);
    return ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u';
}

int main() {
    string text;
    cout << "Enter a sentence: ";
    getline(cin, text);

    int vowels = 0, consonants = 0;
    int n = text.length();
    for (int i = 0; i < n; i++) {
        if (isVowel(text[i])) {
            vowels++;
        } else if (isalpha(text[i])) {
            consonants++;
        }
    }
    cout << "Vowels: " << vowels << endl;
    cout << "Consonants: " << consonants << endl;
    return 0;
}

Common mistakes

  • Counting every non-vowel as a consonant: spaces and + get counted. The first test gives 19 instead of 13.
  • Forgetting capitals: "FUN" adds no vowel, so the result is 5.
  • Writing ch == 'a' || 'e' || ...: always true. Each comparison needs its own ch ==.

Challenge 3 · Reverse and palindrome

medium8 min · 0:32

Practises: backwards loop, building a string with +=, returning a string, ==. The solution includes the extension.

#include <iostream>
#include <string>
#include <cctype>
using namespace std;

string reverseWord(const string& s) {
    string result = "";
    int n = s.length();
    for (int i = n - 1; i >= 0; i--) {
        result += s[i];
    }
    return result;
}

string toLowerCase(string s) {
    int n = s.length();
    for (int i = 0; i < n; i++) {
        s[i] = tolower(s[i]);
    }
    return s;
}

int main() {
    string word;
    cout << "Enter a word: ";
    cin >> word;

    string rev = reverseWord(word);
    cout << "Reversed: " << rev << endl;

    if (toLowerCase(word) == toLowerCase(rev)) {
        cout << word << " is a palindrome." << endl;
    } else {
        cout << word << " is not a palindrome." << endl;
    }
    return 0;
}

Part B: teaching notes

Verified results for the tools table

With s = "COMPUTER": substr(2, 3) → MPU, substr(4) → UTER, find("PUT") → 3, find("U", 5) → npos (the only U is at index 4). "Hello World" after insert(5, ",") → Hello, World, then erase(0, 7) → World. "I like Java" after replace(7, 4, "C++") → I like C++.

Run through the table as a quick-fire quiz: cover the Result column and ask students to predict each answer.

Key explanations

  • Why "Zebra" < "apple": characters are compared by their codes (ASCII). 'A'–'Z' are 65–90 and 'a'–'z' are 97–122, so every capital comes first. To compare alphabetically regardless of case, convert both strings to lower case first.
  • string::npos: it is the largest possible size_t value. Store find's result in a size_t (its real type) before comparing it with npos.
  • char(toupper(...)): toupper returns an int. result += toupper(c) compiles but relies on a conversion. The char(...) makes the intention clear.
  • const string&: the & means "use the original, don't copy" and const means "promise not to change it". Link this to const int a[] from the arrays lessons.

Challenge 4 · Initials

medium7 min · 0:52

Practises: detecting the start of a word, combined conditions, toupper, returning a string

#include <iostream>
#include <string>
#include <cctype>
using namespace std;

string initials(const string& name) {
    string result = "";
    int n = name.length();
    for (int i = 0; i < n; i++) {
        bool startOfWord = (i == 0 || name[i - 1] == ' ');
        if (startOfWord && name[i] != ' ') {
            result += char(toupper(name[i]));
            result += '.';
        }
    }
    return result;
}

int main() {
    string name;
    cout << "Enter a full name: ";
    getline(cin, name);
    cout << "Initials: " << initials(name) << endl;
    return 0;
}

Common mistakes

  • Reading name[i - 1] when i is 0. Short-circuit evaluation of || prevents this, because i == 0 is checked first. Ask students why the order matters.
  • Forgetting name[i] != ' ': extra spaces produce " ." in the output.
  • A simpler approach that "works" on the first test only: take name[0], then the character after each space. It fails on the double-space test, which is why that test is there.

Challenge 5 · Word counter

harder8 min · 0:59

Practises: building a word in a buffer, detecting where a word ends, keeping track of the "best so far"

#include <iostream>
#include <string>
using namespace std;

int main() {
    string text;
    cout << "Enter a sentence: ";
    getline(cin, text);

    int words = 0;
    string current = "", longest = "";
    int n = text.length();

    for (int i = 0; i < n; i++) {
        if (text[i] != ' ') {
            current += text[i];          // still inside a word
        }
        if (text[i] == ' ' || i == n - 1) {   // a word may have just ended
            if (current != "") {
                words++;
                if (current.length() > longest.length()) {
                    longest = current;
                }
                current = "";
            }
        }
    }
    cout << "Words: " << words << endl;
    cout << "Longest word: " << longest << endl;
    return 0;
}

Common mistakes

  • Counting spaces and adding 1: this breaks with extra spaces (the second test gives 10).
  • Missing the last word: if they only check for spaces, a sentence without a trailing space loses its final word. That's what the i == n - 1 check is for.
  • Using >= for longest: "brown" replaces "quick". This is not wrong, but it doesn't match the sample output.

Support

Let weaker students do word counting only, and skip the longest word. Pairing works well here.

Challenge 6 · Word filter

extensionearly finishers

Practises: find with a start position, replace, string::npos, size_t, string(n, ch)

#include <iostream>
#include <string>
using namespace std;

int main() {
    string text, bad;
    cout << "Enter a sentence: ";
    getline(cin, text);
    cout << "Word to hide: ";
    getline(cin, bad);

    string stars(bad.length(), '*');    // a string of * the same length as bad
    int count = 0;

    size_t pos = text.find(bad);
    while (pos != string::npos) {
        text.replace(pos, bad.length(), stars);
        count++;
        pos = text.find(bad, pos + bad.length());
    }
    cout << text << endl;
    cout << "Replaced " << count << " time(s)." << endl;
    return 0;
}

Answer to "Think about it"

With at, the program also hides the "at" inside cat, sat and mat, because find matches anywhere. One fix is to accept a match only when the characters before and after it are spaces or the ends of the string. This is the same start-of-word test as Challenge 4.

Type of pos: students often write int pos. It usually still works, but the compiler warns about comparing signed and unsigned values. size_t is the type find really returns, so teach that.

Mini-project: Password checker

Suggested build order (tell students)

  1. By 1:15: strength returns the correct score. Test it with a single call in main.
  2. By 1:18: rating, and the first do-while loop.
  3. By 1:23: the confirm loop and the hidden output.
  4. Early finishers: tips for each failed rule (the full solution below includes this).
#include <iostream>
#include <string>
#include <cctype>
using namespace std;

// Returns a score from 0 to 5, one point per rule passed.
int strength(const string& pw) {
    bool upper = false, lower = false, digit = false, symbol = false;
    int n = pw.length();
    for (int i = 0; i < n; i++) {
        char ch = pw[i];
        if (isupper(ch)) upper = true;
        else if (islower(ch)) lower = true;
        else if (isdigit(ch)) digit = true;
        else if (!isspace(ch)) symbol = true;
    }
    int score = 0;
    if (n >= 8) score++;
    if (upper) score++;
    if (lower) score++;
    if (digit) score++;
    if (symbol) score++;
    return score;
}

string rating(int score) {
    if (score == 5) return "Strong";
    if (score >= 3) return "Medium";
    return "Weak";
}

void printTips(const string& pw) {
    bool upper = false, lower = false, digit = false, symbol = false;
    int n = pw.length();
    for (int i = 0; i < n; i++) {
        char ch = pw[i];
        if (isupper(ch)) upper = true;
        else if (islower(ch)) lower = true;
        else if (isdigit(ch)) digit = true;
        else if (!isspace(ch)) symbol = true;
    }
    if (n < 8) cout << "  - use at least 8 characters" << endl;
    if (!upper) cout << "  - add a capital letter" << endl;
    if (!lower) cout << "  - add a small letter" << endl;
    if (!digit) cout << "  - add a digit" << endl;
    if (!symbol) cout << "  - add a symbol such as ! or #" << endl;
}

int main() {
    string pw;
    int score;
    do {
        cout << "Choose a password: ";
        getline(cin, pw);
        score = strength(pw);
        cout << "Strength: " << rating(score) << " (" << score << "/5)" << endl;
        if (score < 5) {
            cout << "To make it stronger:" << endl;
            printTips(pw);
        }
    } while (score < 5);

    string again;
    do {
        cout << "Type it again to confirm: ";
        getline(cin, again);
        if (again != pw) cout << "They do not match. Try again." << endl;
    } while (again != pw);

    cout << "Password saved. Hidden: " << string(pw.length(), '*') << endl;
    return 0;
}

Homework (about 30 min)

  1. Finish any challenge not done in class.
  2. Caesar cipher: read a message and a shift (1–25). Print the message with every letter moved forward by the shift, wrapping Z back to A. Keep spaces and punctuation unchanged. Example: Hello, World! with shift 3 → Khoor, Zruog!
  3. Remember the getline trap: the program reads the shift (a number) and the message (a line).
Caesar cipher core idea (for marking)
if (isupper(ch))      ch = char('A' + (ch - 'A' + shift) % 26);
else if (islower(ch)) ch = char('a' + (ch - 'a' + shift) % 26);
